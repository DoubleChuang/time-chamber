# Pause Breathe — 自由潛水呼吸訓練計時器

[English Version](README.md)

專為自由潛水訓練者設計的呼吸計時器：可自訂流程、精準計時、錄影分享。

---

## 功能總覽

| 功能 | 說明 |
|------|------|
| 自訂訓練流程 | 拖拉模組組出 CO2 table、O2 table、拉伸訓練等 |
| 精準計時 | 每個階段獨立倒數，支援暫停、跳過、碼錶模式 |
| 聲音提示 | 階段切換提示音 + 英文語音播報（開始/結束/倒數） |
| 錄影功能 | 訓練過程中同步錄製攝像頭畫面，叠加計時器覆蓋層 |
| 範例編排 | 內建 5 種預設範例，一鍵載入 |
| 分享連結 | 將編排壓縮成 URL，分享後可直接還原 |
| 日曆匯出 | 訓練完成後匯出 ICS 或加入 Google Calendar |
| 雙語支援 | 繁體中文 / English |
| 深色/淺色主題 | Ocean Night（深海夜色）/ Ocean Day（日間淺色） |
| PWA 安裝 | 支援安裝到手機桌面，離線使用 |

## 介面區塊介紹

### 頂部工具列

固定在畫面最上方，包含：

- **品牌 Logo** — 點擊可重新整理頁面
- **版本號** — 顯示目前版本
- **設定按鈕** — 開啟設定面板（語言、主題、提示音、錄影）

### 摘要區（Hero Panel）

顯示目前編排的即時統計：

- **步驟數** — 目前編排展開後的總步驟數
- **總時長** — 所有步驟的秒數總和

### 工具模組區（左側面板）

可拖拉或點擊加入的訓練模組：

| 模組 | 用途 | 說明 |
|------|------|------|
| **吸氣（Inhale）** | 設定吸氣或放鬆呼吸秒數 | 預設 90 秒，可自訂 |
| **閉氣（Hold）** | 設定閉氣訓練秒數 | 預設 75 秒，支援碼錶模式 |
| **競賽倒數（Top）** | 模擬比賽倒數 | 120 秒倒數 + 30 秒 overtime，完整人聲播報 |
| **迴圈（Loop）** | 將一段流程重複數次 | 支援巢狀迴圈（迴圈內的迴圈） |

### 範例編排區（左側面板）

內建 5 種預設範例，一鍵載入後可微調：

| 範例 | 說明 |
|------|------|
| 模擬競賽 | 競賽倒數流程範例 |
| CO2 Table | 8 回合，固定 1 分閉氣，休息逐回遞減 15 秒 |
| 全呼吸 CO2 Table | 8 回合，固定恢復只做一次全呼吸，閉氣 75 秒 |
| 滿肺拉伸 | 8 組：全呼吸 10s → 停頓 30s 拉伸 → 恢復 10s |
| 空肺拉伸 | 8 組：全吐氣 10s → 停頓 20s 拉伸 → 恢復 20s |

### 編排區（中央面板）

主要工作區，用拖拉方式組裝訓練流程：

- 從左側拖拉模組到此處
- 每個模組可設定秒數、模式、重複次數
- 巢狀迴圈支援無限層級（建議不超過 5 層）
- 執行中會鎖定編排區，防止誤觸
- 手機版支援點擊「+」按鈕快速插入模組

#### 閉氣模組的特殊功能

- **碼錶模式（Stopwatch）** — 正向計時，手動按下「完成」結束
- **提醒時間** — 碼錶模式下可設定提醒節點，到達時語音播報已過秒數

#### 迴圈模組

- 設定重複次數（1-100 次）
- 可放入其他模組（吸氣、閉氣、甚至另一個迴圈）
- 執行時顯示目前進度（第 3 / 8 次）

### 訓練執行器（右側面板）

控制訓練的執行：

- **開始** — 使用當下編排的快照開始執行
- **暫停 / 繼續** — 暫停後可隨時繼續
- **跳過** — 跳過目前階段，進入下一個
- **停止** — 終止訓練並重置

執行器顯示：

- 目前階段（吸氣/閉氣/競賽倒數）
- 倒數計時或碼錶計時
- 目前步驟進度（第 X / Y 步）
- 狀態說明

### 分享區（右側面板）

將目前編排分享給他人：

- 自動產生壓縮網址
- 複製連結後傳給朋友
- 對方開啟連結即可載入相同編排

### 錄影功能

在設定中開啟錄影後：

1. 訓練開始時請求攝像頭與麥克風權限
2. 同步錄製攝像頭畫面 + 訓練覆蓋層（計時器、階段名稱、進度）
3. 訓練結束後自動轉換格式（WebM → MP4，如需要）
4. 完成後可：
   - 下載影片
   - 分享影片（手機）
   - 匯出 ICS 日曆檔案
   - 加入 Google Calendar

錄影畫面會顯示浮動預覽窗，可拖動位置或展開/縮小。

## 使用情境

### 情境 1：日常 CO2 Table 訓練

1. 開啟應用程式
2. 點擊「CO2 Table」範例載入
3. 依自己的節奏調整秒數
4. 按下「開始」執行
5. 訓練結束後匯出到行事曆記錄

### 情境 2：比賽前模擬

1. 載入「模擬競賽」範例
2. 調整倒數起始秒數（120s / 90s / 60s）
3. 開啟聲音提示（含完整英文人聲倒數）
4. 開啟錄影記錄訓練過程
5. 訓練結束後下載影片分享給教練

### 情境 3：滿肺 / 空肺拉伸訓練

1. 載入「滿肺拉伸」或「空肺拉伸」範例
2. 迴圈已預設 8 次重複
3. 調整每組的呼吸和拉伸秒數
4. 執行訓練

### 情境 4：自訂訓練流程

1. 從工具模組區拖拉「吸氣」「閉氣」「迴圈」到編排區
2. 在迴圈內放入多個吸氣和閉氣模組
3. 設定每個模組的秒數
4. 調整迴圈重複次數
5. 儲存分享連結給朋友

### 情境 5：碼錶模式挑戰

1. 加入一個閉氣模組
2. 切換為「碼錶」模式
3. 設定提醒時間（例如 1 分、2 分、3 分）
4. 開始後正向計時，到達提醒時間時語音播報
5. 自覺完成時手動按下「完成」
